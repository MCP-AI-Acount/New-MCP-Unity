# 스크린샷 OCR → Google Sheets 파이프라인

## Google (Sheets)
- GCP 프로젝트에서 **Google Sheets API** 사용 설정
- OAuth 클라이언트(데스크톱) JSON을 **MCP_Server/credentials.json** 에 두고, 최초 실행 시 브라우저 로그인 → **MCP_Server/token_sheets.json** 생성 (캘린더용 token.json 과 별도)
- 스프레드시트 URL의 **ID** 를 복사해 `GOOGLE_SHEETS_SPREADSHEET_ID` 또는 MCP 인자로 전달
- 본인 계정으로 만든 시트에 본인 토큰으로 쓰면 됨 (공유 시트는 해당 계정에 편집 권한 필요)

## OCR (Tesseract)
- Python: `Pillow`, `pytesseract` (main rules/packages.txt)
- 시스템: macOS 예) `brew install tesseract tesseract-lang`
- 한글 인식: `OCR_TESSERACT_LANG=kor+eng` (기본값). 한글 팩 없으면 `eng` 만으로 시도

## 템플릿 JSON
- `main rules/sheets_ocr_template.example.json` 참고: `columns`, `extract`(정규식), `append_range`(예: 시트1!A:Z)
- 스크린샷 글자/레이아웃에 맞게 **패턴을 직접 조정**해야 함 (OCR 오인식 시 규칙 완화·키워드 변경)

## CLI
- `python3 collaboration/screenshot_to_sheet_pipeline.py --image ... --template ... --spreadsheet-id ...`
- 또는 `EXE/_run_screenshot_to_sheet.py` 동일 인자
- 먼저 `--dry-run` 으로 OCR·추출 행만 확인 권장
