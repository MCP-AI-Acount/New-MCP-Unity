# 최대 자동화 운영 규칙 (결론)

- 모든 작업의 1순위 목적은 **최대의 자동화**.
- 보안/권한/치명적 데이터 손실 위험이 아닌 한 사용자 확인 없이 직접 처리.
- 사용자 요청이 모호해도, 실행 가능한 최선의 자동화 경로를 먼저 수행하고 결과 보고.

## 사용자 질문/확인 메시지 형식

- 사용자에게 질문·확인할 때는 문장 맨 앞에 반드시 `[질문]` 사용.
- 작업 완료 보고는 문장 맨 앞에 `[완료]` 사용.
- 작업 실패/차단 보고는 문장 맨 앞에 `[문제]` 사용.
- `[완료]`/`[문제]` 보고 시 **왜 그렇게 판단했는지 이유를 반드시 포함**.

## 운영 기본 원칙

- 가능하면 같은 턴에 구현+검증+커밋+푸시까지 끝낸다.
- 반복 수작업은 스크립트/에이전트/대시보드 자동화로 전환한다.
- 같은 종류의 수동 확인 요청은 규칙화하여 이후 자동 적용한다.
