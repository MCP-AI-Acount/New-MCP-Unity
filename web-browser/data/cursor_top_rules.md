# Cursor 최상위 규칙

여기에 규칙을 작성하세요. 웹에서 저장하면 서버의 이 파일에 반영됩니다.

## 대시보드 동기화 고정 규칙

- 밴다이어그램(명령 프로세스) 또는 중요 제한점(기기별/클라우드별 제한)을 수정할 때는 아래 2개를 반드시 함께 수정한다.
  - `web-browser/static/index.html`
  - `web-browser/static/app.js`
- 스타일 변경이 필요하면 `web-browser/static/styles.css`도 함께 수정한다.
- 위 내용 수정 후에는 웹 브라우저 대시보드가 즉시 반영되도록, 같은 작업 턴에서 서버/정적 파일 변경을 완료 상태로 커밋한다.

## 자동화 우선 운영 규칙

- 모든 코드/설정/배포/동기화 작업은 기본적으로 **최대의 자동화**를 목표로 처리한다.
- 보안/결제/권한/파괴적 변경(데이터 삭제, 비가역 작업)처럼 중요한 경우를 제외하고는 사용자에게 중간 확인을 요구하지 않고 직접 진행한다.

## 사용자 응답 접두어 규칙

- `[done]`: 끝까지 전부 이상 없이 완료했어. (최종 마지막 응답에서만 사용)
- `[check]`: 중간에 확인/추가 입력이 필요해.
- `[error]`: 진행 중 오류가 생겼어.
- `[no]`: 질문 자체를 이해하지 못했거나 처음부터 실행이 불가능해.
- `[can’t]`: 현재 기술 스택(Cursor/Google Cloud Run/GitHub) 자체가 지원하지 않아 불가능해.
- `[don’t]`: 기술적으로는 가능하지만, 지금 짜놓은 구조/설정에서는 불가능해.
- `[bug]`: 원래 되어야 하는 동작인데 플랫폼/시스템 버그로 안 돼.
- `[?+영어단어]`: 위 범주 어디에도 정확히 안 들어가.

## 스크립트 파일명 접두어 규칙

- `_scriptname.py` : 사용자가 직접 만들라고 지시한 명령 스크립트 파일.
- `__scriptname.py` : AI가 필수라고 판단해 만든 핵심 스크립트 파일.
- `___scriptname.py` : 필요하지만 패치/버전업 시 삭제될 수 있는 임시성 스크립트 파일.
- `_____scriptname.py` : 테스트 전용 스크립트 파일.
